## AWS.Bedrock/RetrievalInstructionProperties
### Properties
* **Arn**: string (ReadOnly, Identifier): The Amazon Resource Name (ARN) of the resource.
* **CreatedAt**: string (ReadOnly): When the retrieval instruction was created. On a numbered version, when that version was created.
* **CustomerEncryptionKeyArn**: string: The ARN of the customer managed KMS key protecting this content, when one was supplied at create.
* **Description**: string: A description of the retrieval instruction. On a numbered version, the description of that version.
* **Instruction**: [Instruction](#instruction) (Required): The reviewed content this instruction serves ? what AgenticRetrieveStream resolves while status is ACTIVE. Absent until the first create review passes. Always present on a numbered version.
* **LastTransitionStatus**: string (ReadOnly): The outcome or in-progress state of the most recent create or update. CREATING or UPDATING means the operation is still running. Independent of status. Always has a value from the create 202 onward. On a numbered version this is always CREATE_SUCCESSFUL: a version is created once, from reviewed content, and is immutable.
* **Name**: string (Required): The name of the retrieval instruction.
* **RetrievalInstructionId**: string (ReadOnly): The identifier of the retrieval instruction.
* **Status**: string (ReadOnly): Whether the instruction can be used. Only ACTIVE is resolvable at retrieval time. Monotone: INACTIVE to ACTIVE once, never back. Numbered versions are always ACTIVE.
* **Tags**: [Tag](#tag)[]: An array of key-value pairs to apply to this resource.
* **UpdatedAt**: string (ReadOnly): When the retrieval instruction was last updated. Equal to createdAt on a numbered version, which is immutable.
