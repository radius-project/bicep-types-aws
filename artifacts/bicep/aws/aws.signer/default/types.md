## AWS.Signer/SigningJobProperties
### Properties
* **Arn**: string (Identifier): The ARN of the signing job.
* **CompletedAt**: string (ReadOnly): Date and time that the signing job was completed.
* **CreatedAt**: string (ReadOnly): Date and time that the signing job was created.
* **JobId**: string (ReadOnly): The ID of the signing job.
* **JobInvoker**: string (ReadOnly): The IAM entity that initiated the signing job.
* **JobOwner**: string (ReadOnly): The AWS account ID of the job owner.
* **PlatformDisplayName**: string (ReadOnly): A human-readable name for the signing platform associated with the signing job.
* **PlatformId**: string (ReadOnly): The microcontroller platform to which the signed code image will be distributed.
* **ProfileName**: string (Required): The name of the signing profile.
* **ProfileVersion**: string (ReadOnly): The version of the signing profile used to initiate the signing job.
* **RequestedBy**: string (ReadOnly): The IAM principal that requested the signing job.
* **SignatureExpiresAt**: string (ReadOnly): The expiration timestamp for the signature generated by the signing job.
* **SignedObject**: [SignedObject](#signedobject) (ReadOnly): The S3 location of the signed code image.
* **Source**: [Source](#source) (ReadOnly): The S3 bucket that contains the object to sign.
* **Status**: string (ReadOnly): Status of the signing job.

## AWS.Signer/SigningProfileProperties
### Properties
* **Arn**: string (ReadOnly, Identifier): The Amazon Resource Name (ARN) of the specified signing profile.
* **PlatformId**: string (Required): The ID of the target signing platform.
* **ProfileName**: string (ReadOnly): A name for the signing profile. If you don't specify a name, AWS CloudFormation generates a unique physical ID and uses that ID for the signing profile name. 
* **ProfileVersion**: string (ReadOnly): A version for the signing profile. AWS Signer generates a unique version for each profile of the same profile name.
* **ProfileVersionArn**: string (ReadOnly): The Amazon Resource Name (ARN) of the specified signing profile version.
* **SignatureValidityPeriod**: [SignatureValidityPeriod](#signaturevalidityperiod): Signature validity period of the profile.
* **Tags**: [Tag](#tag)[]: A list of tags associated with the signing profile.
